# UI Consistency Skill

Use this skill whenever creating or modifying PlacementOS UI.

## Principles

The interface should be:

- simple;
- professional;
- readable;
- responsive;
- accessible;
- information-dense without being cluttered.

PlacementOS is a daily control panel, not a visual-effects showcase.

## Design system

Reuse established:

- spacing;
- typography;
- colors;
- component variants;
- borders;
- radius;
- icons;
- interaction patterns.

Do not introduce new visual styles for individual screens without a reason.

## User priority

The user should reach:

- today's priority;
- next action;
- urgent deadline;
- current progress;

quickly.

Avoid unnecessary onboarding or decorative screens.

## Responsive behavior

Every important screen must work on:

- desktop;
- smaller laptop screens;
- mobile widths.

Do not assume a wide monitor.

## Accessibility

Prefer:

- semantic HTML;
- keyboard-accessible controls;
- visible focus states;
- sufficient contrast;
- descriptive labels;
- accessible form controls.

## Visualization

Charts must communicate useful information.

Do not add charts merely because a dashboard feels incomplete without them.

## Animation

Use animation sparingly.

Animation must not interfere with:

- readability;
- task completion;
- accessibility;
- performance.

Prefer subtle transitions over decorative effects.
